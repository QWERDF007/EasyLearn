## 推荐体验顺序

1. 将鼠标移到摘要块，观察原文与译文同时出现蓝色高亮；移开后恢复固定选择。
2. 点击“问题定义”，检查两侧定位；使用勾选框或 Ctrl / ⌘ + 单击选择多个块。
3. 编辑摘要译文并保持“锁定”勾选，保存后点击“重译”。人工译文应保留，自动候选出现在修订记录中。
4. 打开 AI 解读，调整相关块，点击“解释这段”。完成后点击引用，观察证据定位，但本次问题锚点不变。
5. 关闭浮层后选择其他块，再打开浮层：已有问题保持原证据；点击“使用当前选择”开始新问题。
6. 在 v2 提问后切换到 v1，再点击旧回答的引用：页面回到该回答对应的 v2。
7. 导出中文 Markdown 或 ZIP，检查人工修订、公式、表格及版本清单。

## 示例的实现范围

- 可交互：多块联动、版本隔离、人工修订与锁定、修订回退、问题锚点、相关块选择、引用跳转、模拟生成/停止、浏览器本地记录、有效结果导出。
- 采用自编英文文档和译文，不复刻真实论文。表格数值明确为示意数据。
- 原文以 HTML 页面模拟；JSON 中明确标记 `demo_dom_region`，不伪造 MinerU 坐标，也不验证真实 PDF.js 坐标转换。
- LLM 回答、任务进度和自动重译使用内置数据。服务选择不会发起网络请求；上传入口不会上传或解析文件。
- 页面中的示例 ZIP 包含原文、译文、JSON 和 manifest；它与本交付资料包用途不同。
- 刷新后保留已保存译文、提问记录与草稿。刷新时尚未完成的演示生成标为已停止；真实 SSE 恢复与任务接管以完整方案为准。
- 浏览器限制 `file://` 本地存储时，当前页仍可交互，但关闭后不保证保留记录。“区域说明”中的重置按钮可清除本示例数据。
- HTML 的界面与状态演示不等于 FastAPI 后端已经开发，也不替代方案中的真实文档、模型和故障验收。

中文字体为 Noto Sans CJK 的嵌入子集，许可说明附在 HTML 内及交付包中。
