# 005: 让原文编辑和工作台浏览器契约可用

## What to build

把 source edit 的结构语义和浏览器 wire/DOM 契约收敛到真实用户路径。单节点块可继续使用块级编辑；多节点块必须按节点编辑或使用结构化编辑，禁止用一个字符串覆盖并清空其他节点。页面只渲染有真实后端字段和事件接线的控件。

## Acceptance criteria

- [x] 多节点块的编辑请求包含每个被修改节点的真实文本和 revision，不发送伪造的空文本。
- [x] 空文本仍按现有内容约束拒绝；节点删除若未定义独立契约，不通过空文本隐式实现。
- [x] 乐观并发冲突向用户返回可识别错误，并保留最新服务端内容。
- [x] 页面初始化时所有必需控件和监听器均存在；缺少可选控件不会阻断无关功能。
- [x] 设置控件要么提交受支持的 parse/translation 字段并在任务详情可观察，要么从界面移除。
- [x] 上传、解析、删除对话框、任务轮询、source edit 和 stale 状态均通过集中 wire adapter 消费稳定字段。
- [x] 真实浏览器 smoke 覆盖页面启动、上传、解析提交、删除对话框、设置提交和多节点编辑。
